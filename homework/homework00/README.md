# Homework 00: pre-class setup

Stage 00 is about getting the machine ready rather than about data. This folder holds the evidence that the environment described in the Stage 00 setup instructions actually works.

## Files

- `python_tutorial.ipynb` records the interpreter version, the active environment, and the imports the course depends on, so the output itself is the proof that the toolchain is installed correctly.

The repository is the other half of this stage's deliverable. Its layout follows `course_git-repository-structure.pdf`: `class_materials/` for instructor handouts and lecture scratch files, ignored by git; `homework/` for the graded per-stage exercises; and `project/` for the cumulative Weekly ETF Risk Monitor.

Per the structure document, homework00 holds no data folders. There is no acquisition, cleaning, or modelling at this stage, so creating `data/raw/` here would contradict the rule that each homework folder contains only the folders that week uses.
