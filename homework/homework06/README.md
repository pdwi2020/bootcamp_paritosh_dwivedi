## Cleaning strategy

`fill_missing_median` fills missing values in all numeric columns by default or in a specified numeric subset. Median filling assumes the observed values provide a reasonable center for the missing observations. It retains rows and is less affected by extreme values than mean filling, but it compresses variance, weakens relationships among variables, and can hide informative missingness.

`drop_missing` has two documented modes. Without a threshold, it drops rows that are missing any value, optionally considering only specified columns. With a threshold, it does not drop rows; it drops columns whose missing fraction strictly exceeds the threshold, optionally among specified candidate columns. The notebook uses a 70% threshold to remove `extra_data`, which is missing in five of seven rows. This assumes a column with so little coverage cannot support a stable comparison. The tradeoff is losing the two recorded values and any signal they may contain.

`normalize_data` min-max scales all numeric columns by default or a specified numeric subset. Constant columns map their nonmissing values to 0.0 because they contain no relative variation; missing values stay missing. Min-max scaling preserves order and places measures on a common range, but it is sensitive to outliers and to future values outside the fitted range.

The notebook drops the sparse column, fills the retained continuous measures, and then normalizes them. Dropping first prevents a mostly empty field from being filled into a misleading feature. Filling before scaling ensures every retained observation is expressed on the same unitless scale. In this sample, a median lies within the observed range, so it does not change the observed minimum or maximum. It changes the previously missing cells from missing values into scaled median values.

`zipcode` is excluded from filling and scaling even though pandas reads it as numeric. It is an identifier, so numeric distance between zip codes has no measurement meaning. `city` is also retained as a categorical label rather than encoded in this preprocessing exercise.

## Dropping compared with filling

Dropping rows is appropriate when the missing share is small, the affected rows are not systematically different, and the missing field is required for a valid record. It also avoids inventing values. The cost is a smaller sample, and the result can be biased when missingness is related to the outcome or another subgroup.

Filling is preferable when retaining observations matters and a defensible replacement rule exists. For this seven-row sample, each dropped row would remove about 14% of the data, so median filling is used for `age`, `income`, and `score`. For a forecasting workflow, fill values and scaling bounds must be learned on training data only to prevent information from the evaluation period leaking into preprocessing.
