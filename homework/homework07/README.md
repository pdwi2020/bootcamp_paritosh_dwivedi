# Homework 07: outliers and risk assumptions

This homework implements three outlier treatments, tests them against a dataset whose answer is known, and only then applies them to real market data where it is not.

## Files

- `homework07_outliers-risk-assumptions_submission.ipynb` runs the full sequence: validation, application, sensitivity analysis, and reflection.
- `src/outliers.py` holds the reusable detectors. `detect_outliers_iqr(series, k=1.5)` uses the Tukey fence; `detect_outliers_zscore(series, threshold=3.0, *, robust=False)` covers both the classic standard-deviation rule and a median/MAD variant behind the `robust` flag; `winsorize_series(series, lower=0.05, upper=0.95)` clips instead of dropping. `MAD_TO_SIGMA = 0.6745` rescales the median absolute deviation so the robust threshold is comparable to a conventional sigma.
- `data/raw/outliers_homework.csv` is generated by the starter Setup cell and injects five known shocks on specific May 2022 dates.
- `data/raw/api_source-yfinance_symbol-SPY_20260822-150518.csv` is the real SPY comparison set.
- `data/processed/spy_outlier_treated.csv` is the treated output.

## Why both datasets

A detector that has never been tested against a known answer is a guess. The synthetic set has five deliberately planted shocks, so it can measure whether each method finds them and how many ordinary points it takes along with them. All three detectors recover all five, and the classic z-score does it with no false positives, because that data is normal by construction.

Real returns invert the ranking. The classic z-score flags 1.33% of sessions against the IQR fence's 6.32% and the robust z-score's 4.99%. This is the masking problem: fat tails inflate the standard deviation with the very days the rule is meant to catch, so the three-sigma bar drifts out of reach. Quantile-based methods have no such feedback loop. A method that wins on synthetic data and under-detects on real data is not the one to carry forward.

## What the sensitivity analysis shows

On the synthetic set, deleting the IQR-flagged points drops R-squared from 0.96 to 0.57, because the fence removed four ordinary points along with the five shocks. On real returns the same operation flattens the slope, because the removed days carried the signal. Winsorizing sits between the two: it preserves every row and every date while damping the tails, which matters for a time series where deletion leaves gaps.

The governing assumption is that a flagged point is worth examining rather than deleting automatically. The synthetic shocks were errors by construction; the real SPY tails are recognisable market events. A market event is kept, a data error is removed.
